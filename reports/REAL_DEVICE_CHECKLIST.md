# Physical-device and assistive-technology review

Status: **not yet performed**. Browser emulation and Playwright WebKit do not replace
testing Safari on an iPhone, Chrome on an Android phone, or a screen reader.
Record the device, OS/browser version, date, route, finding and outcome for each check.

## Android phone / Chrome

- [ ] At 100% zoom, open the portfolio and all seven demos in portrait and landscape.
- [ ] Check menus, fixed headers, charts, cards and dialogs for clipping or overlap.
- [ ] Create/edit/save a task in NOVA, ATLAS and RELAY; reload and verify persistence.
- [ ] Add/edit a NILA transaction; verify keyboard does not obscure inputs or save controls.
- [ ] Complete AURA enquiry, VANTA cart and RASA quiz; check touch targets and scroll locking.
- [ ] Download the résumé and a CSV/itinerary; open the files with installed phone apps.
- [ ] Check slow network, offline navigation after a fresh load and GitHub error/retry states.

## iPhone / Safari

- [ ] Repeat portrait/landscape checks on a physical phone.
- [ ] Check dynamic browser bars, safe areas, text sizing and on-screen keyboard.
- [ ] Verify date/select controls, modal scrolling, focus return and file downloads.
- [ ] Verify local data after refresh and reopening the browser; note private-mode differences.
- [ ] Use pinch zoom and system Larger Text to inspect essential content and controls.

## Screen reader

- [ ] NVDA with Firefox/Chrome: landmarks, heading order, link names and skip links.
- [ ] VoiceOver on iPhone: browse cards, open/close dialogs and verify focus restoration.
- [ ] Read task forms, required fields, validation errors, loading/error messages and status changes.
- [ ] Verify chart summaries, feedback-pin descriptions and budget values make sense without visuals.
- [ ] Confirm background controls cannot be activated while a modal is open.
